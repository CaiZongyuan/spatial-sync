## 0. 原则

1. **克制**：灰阶为主；一个靛蓝强调色只标"运行中、已选中、agent 提出"；绿、琥珀、红平时只是小圆点，只有 critical 告警才给表面着色。
2. **框架统一，页面各取所长**：所有页面在同一个可折叠侧栏框架内；概览、实况、库用图优先布局，计划、训练、审批用闭环看板布局，其余用控制台面板布局。
3. **数据驱动，不虚构**：界面只展示 API 返回的数据；没有数据时显示设计过的空状态，不放占位数字。
4. **离线可用**：字体、图标、3D 资源全部本地；不访问任何外部网络。
5. **不破坏现有契约**：现有工作台、回放、平台概况的功能与 `data-testid` 保留，迁入新框架。

### 1.2 字体

| 角色 | 字体 | 用途 |
|---|---|---|
| 展示 | Noto Serif SC → 系统宋体（Songti SC、STSong、Source Han Serif SC）→ serif | 页面标题、大数字、卡片标题、审批卡标题 |
| 界面 | IBM Plex Sans → PingFang SC、Microsoft YaHei、Noto Sans CJK SC → sans-serif | 正文、控件 |
| 等宽 | IBM Plex Mono → 系统等宽 → 中文无衬线回退 | ID、数值、眉标、图号 |

字号阶梯：10.5 / 12.5 / 14 / 15 / 17 / 19 / 26 / 32–48 px。数值列一律 `tabular-nums`。字体随应用打包（IBM Plex 拉丁字形），中文依赖系统字体；不从网络加载。

### 1.3 间距、圆角、阴影、动效

- 间距：4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 px。
- 圆角：4（标签）/ 7（按钮、输入）/ 12（面板）/ 16（大容器）px。
- 面板：1 px `--line` 描边 + 1 px 内顶高光 + 很淡的长阴影；不给每个块都加卡片样式。
- 深色保留全页极淡的胶片颗粒（固定定位、不拦截指针，透明度 0.16）；现有深色令牌值不变。
- 浅色以暖纸为底面：暖棕暗点、白色亮点、2–4% 的低频云斑，加左上固定顶光与略暖的边缘；`--grain-o: 0`。纸纹只铺在页面底面，面板、卡片与视口保持光滑。`--paper`、`--paper-size`、`--paper-att` 定义纸面；深色分别为 `none`、`auto`、`scroll`。
- 浅色的三个确定性纸纹图砖预计算为本地透明 PNG，原始 SVG 保留为美术源；两个渐变、平铺尺寸与附着方式不变，页面不运行这三个纸纹滤镜。
- 浅色面板阴影为 `inset 0 1px 0 #fff, 0 0 0 .5px rgb(48 38 18 / 3%), 0 1px 2px rgb(48 38 18 / 7%), 0 20px 40px -26px rgb(48 38 18 / 36%)`。
- 动效：150–250 ms，`cubic-bezier(.2,.7,.2,1)`；`prefers-reduced-motion` 时关闭动画。

### 1.4 3D 材质令牌

视口材质颜色、灯光强度、接触阴影浓度也来自令牌（`--m-floor`、`--m-wall`、`--m-body`、`--m-steel`、`--m-glass`、`--m-edge`、`--m-sky`、`--m-sun`、`--m-hemi`、`--m-key`、`--m-ao` 等，取值见原型）。切换主题时视口重新读取令牌，不重新加载场景。

浅色轮廓为 `--m-edge: #4f4c45`、`--m-edge-o: .74`；主光 `.70`、半球光 `.54`、接触阴影 `.50`，地面色 `#e2ded4`。地面平面只接收阴影，画布透明，透出 §1.1 的舞台渐变；实际场景与静态预览使用同一渲染规则。

## 2. 框架

### 2.1 布局

- 左侧图标侧栏 + 右侧页面。侧栏展开宽 212 px（图标 + 名称 + 徽标），折叠宽 44 px（只有图标，悬停与聚焦时显示提示）。折叠状态保存在浏览器本地。
- 视口宽度 ≤ 900 px 时，侧栏变为顶部横向滚动的导航条，品牌副标题和侧栏底部信息隐藏。
- 页面区：顶部是面包屑和状态芯片（待审批数、告警数、异常数）；其下是页头（衬线标题、副标题、页面级操作）；再下是页面内容。
- 内容最大宽 1520 px；左右留白 `max(16px, safe-area-inset)`。

默认跟随系统；无法判断时用深色。侧栏底部提供主题切换，手动选择保存在浏览器本地。

## 4. 3D 视口

- 沿用现有场景视口组件（react-three-fiber），新增**正交等距相机预设**（略低于标准等距的俯角，Z 轴向上），与现有透视轨道相机并存；概览、实况、库缩略图默认等距，会话页可切换。
- 渲染场景 Manifest 的真实视觉：实体的 GLB 或基本几何体、布景的静态 GLB。**不移植原型的程序化设备模型**；原型只定义观感：柔和半球光 + 暖色主光与软阴影、物体下的模糊接触阴影、1 px 折边线（透明度来自令牌）、剖切墙、向外淡出的地面网格。
- **叠加层**（HTML / SVG，位于画布上方）：设备名与读数浮标（自动错开避免重叠）、告警红点（脉冲，确认后变空心）、TCP 虚线路径（流动虚线）与目标环、成功提示。叠加层元素可聚焦、可点击。
- **交互**：点击设备或其浮标选中并打开抽屉；悬停高亮描边；"读数"开关显示或隐藏读数浮标。
- **取景**：新场景在首个空间样本与初始视觉、已请求的路径预览就绪后自动取景一次；加载期间开始环绕、平移或缩放也会接管视角。后续姿态、视觉与预览更新不覆盖该视角；调整面板或窗口尺寸只更新投影。切换投影是显式操作，可初始化对应预设。每个可交互视口（含紧凑概览与预览）提供“重新取景”；缩略图在实际完成初始取景后才采集。
- **取景范围**：场景按可见实体的几何范围稳健聚合，individual 与 instanced 对同一实体采用相同权重；远离主体或过大的几何只排除于取景，仍按权威姿态渲染并可在检查器查看。场景 UI 默认取景半径至多 20 m、轨道距离至多 100 m，并限制正交缩放；这不是协议、场景或物体合法性的限制。无法形成可用范围时保留先前取景，新视口使用实验室默认视角。素材详情以真实静态模型的完整范围、中心和相对裁剪面取景，不套用场景的绝对尺度限制。
- **路径预览**：选中机械臂步骤时，按预览接口返回的 TCP 折线画虚线，在目标关节角处画半透明幽灵臂（复用机器人视觉，材质换为半透明强调色）；策略驱动步骤只画目标环和"由策略执行"标记。
- **训练视图**：2 × 2 平铺的只读小视口，每个显示一个环境；10 Hz 更新；左上角标 `env n`。
- **缩略图**：素材与场景的卡片缩略图、列表 72 px 小图由一个共享离屏渲染器生成并缓存；没有 WebGL 时显示线稿回退。
- **性能**：同一页面的多个视口共享一个 WebGL 上下文；不可见视口不渲染。

## 5. 页面契约

每页列出布局、面板、数据来源和交互。数据来源中的接口见 PRD 的 HTTP API 总览与各技术规格。

### 5.1 概览 `/`

- **布局**：顶部告警横幅（有活动 critical 告警时）；图优先区（左：活动会话的等距视口，可点击设备；右：设备抽屉）；其下两列：左列"近期活动"时间线与"RSI · 参照与候选"表，右列检查器。
- **检查器分节**：活动会话（会话、场景、物理源、设备、观察者）；GPU 租约（节点、设备、显存与进度条）；队列与审批（运行中、排队、失败、待审批 + 跳转）；告警（活动告警数 + 跳转）；成本 · 今日（LLM 估算、Token、GPU 小时、未读异常 + 跳转）。
- **数据**：会话与场景、Manifest 与状态流、告警、收件箱或事件（近期活动）、审批、作业与节点、成本摘要、RSI 参照与候选。
- **无活动会话时**：视口区显示最近启动的场景版本缩略图和"去场景库启动"按钮。
- **上线**：W0 显示会话、近期活动与检查器的现有部分；其余分节随对应里程碑出现。

### 5.2 实况 `/live`

- **布局**：图优先区（实况布局底图的等距视口 + 设备抽屉）；"告警"分节（活动与最近告警表 + 已声明规则表 + 收件箱提示）；"设备"分节（2 列设备卡，告警设备排在最前；每个数值附迷你曲线）；"来源"与"历史"分节（Device Host、broker、标识空间、保留时长；`lw history` 命令框）。
- **数据**：`/live/entities`、`/live/state` + 状态流、`/alerts`、`/history`（迷你曲线，每个属性 1 小时、1 分钟粒度）。
- **交互**：确认告警（带备注），可取消尚未提交的确认表单；提交后不可撤销，首次操作者与备注保留，恢复由条件不再成立时自动转为 `cleared`；"读数"开关；点击设备打开抽屉；复制历史命令。
- **L1 时**：页面先展示仿真会话中的设备（培养箱、生物安全柜等虚拟设备）；L3 后切换为实况设备，仿真设备回到会话页。

### 5.3 素材库 `/assets` 与素材详情 `/assets/{kind}/{name}/{rev}`

- **列表**：工具条（数量、说明、卡片 / 列表切换、种类筛选、"只看缺口"、搜索）。卡片视图：3 列（≤ 1100 px 两列，≤ 560 px 一列），每卡缩略图 + "图 n · ID" + 名称 + 完整度圆点 + 首个缺口芯片。列表视图：72 px 小图、ID 与名称、种类、尺寸、实现类型、完整度圆点、缺口芯片。
- **详情**（控制台布局）：左列预览（大视口）、完整度清单（六项，每项 有 / 警告 / 缺 / 不适用 + 说明）、绑定模板表；右列属性键值（ID、种类、尺寸、实现类型、来源、许可证、不可变版本）、实体类型（属性、动作、前置条件）、引用它的场景、删除（产生审批）。
- **数据**：`/library/assets`、`/library/assets/{kind}/{name}/{rev}`、`/library/files/...`（缩略图、GLB）。

### 5.4 场景库 `/scenes` 与场景详情 `/scenes/{name}/{rev}`

- **列表**：同素材库，卡片显示物理源、来源、可启动芯片、实体数与绑定数、说明或失败原因（红字）；列表视图增加"实体 / 绑定"列。
- **详情**（控制台布局）：左列视口（等距，带读数开关）、实体表、示教位置与布景；右列操作（可启动芯片 + "启动会话"主按钮；不可启动时按钮禁用并显示原因）、验证报告（结构、物理，每项结论与说明）、属性（场景、物理源、构建方式、来源、求解器、预热、尺寸）、相关录制。
- **交互**：启动会话后跳转到会话详情。
- **数据**：`/library/scenes`、`/library/scenes/{name}/{rev}`、`/library/authoring-reports`、`POST /sessions`。

**SF 增量页面契约（已实现，原型 A：场景优先）**：

- 主区域展示选定的已接收 Scene Version，旁侧展示版本、固定 Asset 依赖和平台验证报告；外部提交记录作为详情中的只读区域，展示来源、报告时间和接收时间。
- 外部摘要按纯文本显示，最多 64 KiB；附件仅为产物引用。没有提交时显示“未收到更新”，不推断外部制作进度；外部完成声明不能覆盖平台验证。
- 未提交的 Blender 编辑不改变预览、版本或验证结果。新版本拥有独立报告，验证未通过时沿用既有启动限制；历史版本和录制保持可读。
- 可复制带精确版本与失败项的摘要回原对话；复制不自动发送消息。需求、参考图、灰盒确认和修改仍在外部对话／工厂中进行。

### 5.5 计划 `/plans` 与计划详情 `/plans/{id}`

- **布局**：顶部具身层阶段条（当前阶段"计划"高亮）；计划列表（ID、名称与提交者、种类标签、状态芯片、修订、审批方式）；下方详情。
- **操作计划详情**：左视口（聚焦机械臂工作台，路径预览）、右步骤清单（计划头：名称、种类、修订、提交者、审批方式；修订差异提示；步骤清单；执行方式分段"示教轨迹 / 策略"只在预览中切换显示；当前步骤的 `lw do ... --plan --step` 命令框）。
- **训练计划详情**：计划块（目标、Task 版本、算法、模型、规模、预计时长、预算、成功标准；相对上一轮的变化表；假设；agent 理由）+ 访谈记录表（问题、agent 推荐、人的回答）。
- **数据**：`/plans`、`/plans/{id}`、`/plans/{id}/steps/{n}/preview`、`plan.update` 消息。

### 5.6 训练 `/train` 与作业详情 `/train/jobs/{id}`

- **页头操作**：层切换分段"具身层 · {目标} / Agent 层 · {Agent}"。
- **具身层**：阶段条（素材、场景、计划、作业、评估、策略）；参照 / 候选对；RSI 看板（CI 须线图 + 目标线 + 接受线 + 版本表）与闭环预算、实验记录并排；作业表；训练计划（待审批）与计算节点并排。
- **Agent 层**：阶段条（Harness、评估集、运行、评分、接受、成本）；参照 / 候选对；Agent 看板（每版本均分 + 最低到最高须线，被拒版本空心）与预算、实验记录；Harness 版本表；Agent 运行作业表与参照 Harness 组成。
- **作业详情**（控制台布局）：统计条（iteration 与进度、mean reward、train success、已用 / 剩余）；左列训练视图（仅运行中）、指标摘要（两张面积折线，TensorBoard 链接）、检查点表（提升为策略 → 产生审批）、评估（成功率、分阶段条、回合表与回放链接）；右列检查器（作业、状态、Task、节点、物理、两端 Newton 版本、TensorBoard）、训练计划。
- **数据**：`/loops/{goal}`、`/jobs`、`/jobs/{id}`、`/jobs/{id}/view`（WebSocket）、`/evaluations`、`/notebooks/{goal}`、`/agents/{id}/versions`、`/agents/{id}/runs`、`/nodes`。

### 5.7 评估 `/eval` 与评估集详情 `/eval/{suiteId}`

- **列表**：两列评估集卡（ID、层标签、目标说明、被测对象、环境、划分、参照与候选、版本轨迹、"打开计分板"）；角色与可见性面板（四列：Builder、Optimizer、Evaluator、Target，各自可见与不可见）；最近评估表与接受规则并排。
- **详情**：可比较条件行（变量标签用强调色，固定条件用普通标签，右侧说明）；计分板（Agent 层：版本、模型与思考等级、均分、运行范围、成本、时长、日期、判定；具身层：版本、控制器、成功率、95% CI、训练成本、评估时长、日期、判定；最后一行锁定的 held-out test）；分数曲线；Agent 层逐题得分表（题目、评分维度、两个版本、变化、合计行），具身层分阶段通过率与评估回合；评分方式说明（私有条件锁图标）；角色与可见性。
- **数据**：`/suites`、`/suites/{id}`、`/suites/{id}/scoreboard`、`/evaluations`。

### 5.8 成本 `/cost`

- **页头**：标题"成本与统计"。
- **筛选条**：Agent 选择、模型选择、范围分段（最近一小时、最近一天、近 7 天、近 30 天、自定义；自定义时出现起止日期）。
- **摘要**：今日、近 7 天、累计三张卡，每张 2 × 2：Token、请求、LLM 成本（估算）、GPU 小时。
- **图表**（两行两列）：
  - 请求 · 按 Agent：堆叠柱（每个 Agent 一段，系列色 c1–c3），**上方独立比率带**画各 Agent 成功率虚线（只标实际达到的范围，不强制 0–100%）；
  - Token：输入 / 输出 / 缓存读取堆叠柱，上方比率带画缓存命中率；
  - LLM 成本：折线 + 面积，标峰值与末值；下方可展开数据表；
  - GPU 小时：按节点分组、按作业的横向条，运行中作业用强调色；未接入节点显示 0。
  - 悬停显示提示框（时间桶 + 各系列值）；键盘用户通过数据表获得同样数字。
- **分摊**：按 RSI 目标和按计划两张表（请求、Token、LLM 估算、GPU、占比）。
- **异常**：列表（严重度芯片、标题、详情、时间、标为已读）；"全部标为已读"。
- **页脚**："Token 与 GPU 小时为平台精确记录，金额按价格表估算。"
- **粒度**：最近一小时按 5 分钟、最近一天按小时、7 / 30 天按天、自定义 92 天内按天，更长按周。
- **数据**：`/cost/summary`、`/cost/series`、`/cost/breakdown`、`/cost/anomalies`。

### 5.9 资源 `/resources/{gpu|models|robots}`

- **标签页**：算力（节点数）/ 模型（LLM 数 · 机器人模型数）/ 机器人（本体数）。
- **算力**：每个节点一块面板（设备、显存、租约持有者与开始时间、预计释放、训练物理；GPU 利用率 1 小时曲线；显存条）；租约队列表；未接入节点为虚线面板。W0 时把现有平台概况的主机资源（CPU、RAM、GPU、进程）与托管后端迁入本页。
- **模型**：LLM 表（提供方、model_id、默认思考等级、凭据名与掩码、健康、延迟 p50、价格 输入 / 输出 / 缓存读、使用者）+ Vault 说明 + "编辑价格表"；机器人模型目录表（模型、类型、来源、许可、支持本体、动作空间、推理算力、状态）。
- **机器人**：每个本体一张卡（左：3D 缩略图 + 本体、entityKey、素材、场景；右：控制器栈）；控制器版本历史表；真机卡片未接入时整体灰化。
- **数据**：`/nodes`、平台概况接口、`/models`、`/prices`、`/vault`（只返回名称）、`/robot-models`、`/embodiments`、`/controllers/{id}`。

### 5.10 待审批 `/approvals`

- **布局**：具身层阶段条；两列：左"收件箱"（待处理审批卡）与"已处理"（可撤销），右活动时间线。
- **审批卡**：见组件。训练计划卡显示假设与访谈记录；策略提升卡显示 train 与 test 成绩和接受规则判定，test 低于参照时标红提示；超预算卡显示预计与剩余预算；删除卡显示引用方。
- **交互**：批准、驳回（可附备注）；已处理可在执行前撤销。
- **数据**：`/approvals`、收件箱或事件流（时间线）。

### 5.11 会话 `/sessions` 与会话详情 `/sessions/{id}`

- **数据**：现有会话接口、平台概况接口、`/plans`。

### 5.12 录制 `/recordings` 与回放 `/replay/{id}`

## 7. 可访问性与响应式

- 验收范围是桌面 Web；窄屏（≥ 400 px）要求不横向滚动、不破版：表格在自身容器内横向滚动，多列布局折为单列，侧栏变顶部导航。
- 所有交互元素可键盘到达，焦点可见（2 px 强调色描边）；标签页支持方向键；视口中的设备可通过浮标按钮聚焦与选择。
- 图表提供文字替代（`aria-label` 概述 + 可展开数据表）。
- 尊重 `prefers-reduced-motion`：关闭脉冲、流动虚线、旋转与过渡。
