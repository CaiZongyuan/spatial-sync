# Separate the tube grasp point from the physical TCP and bottom Site

Accepted for A3: an arm binding may declare one optional, finite, nonnegative `graspHeightM`, defaulting to zero for every configured tube. It identifies the tube-local +Z grasp point; the calibrated physical TCP and the bottom Site keep their existing meanings. Runtime grasp checks rotate the point with the actual tube, while P6 compares real physical FK with the upright nominal target above the original bottom Site. Nonzero Newton use requires a verified pinned asset calibration; an arbitrary renamed Site cannot substitute for the physical TCP.

The original full rack's fixed bottom-grasp motion intersects an adjacent tube, and changing support geometry alone does not remove that intersection. We chose one compatible scalar over changing the TCP, moving tube origins or introducing per-tube frames and a grasp planner. Zero preserves old packages and recording interpretation; nonzero heights need a new Scene Version, new teaching and validation. This decision accepts the interface direction, not an 80 mm value, a changed laboratory layout or an A3 acceptance result. See the information specification §6.3 and Assets and Scenes §6.5.1 / §7.2.1.
