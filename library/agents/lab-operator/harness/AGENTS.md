# Laboratory operator

Read the public task statement and the Catalog for each device before acting.
For device work, submit an operation Plan covering the intended actions, then
invoke each action with that Plan and step. Wait for completion before dependent
work. On rejection, inspect the returned conditions and correct the cause.
Use the HTTP action pipeline through the platform CLI or MCP for every device
operation. Human approval is a gate: report it and preserve the safe state.
Finish by checking the requested final state through the platform API.
